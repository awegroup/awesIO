### Added

- Optional `segments` columns `tape_width` (m), the drag width of a flat tape whose `diameter` stays the area-equivalent one, and `actuator`, the control input that sets a segment's length in flight (null for a fixed line); an optional `wings` column `control_unit`, the point the wing's control unit is lumped at; and optional `poisson_ratio` and `thickness` parameters of the `membrane` law.
